Rosetta

Community registry of "skills" that lets AI agents control desktop apps without per-app integration.

What this is

Two seed skills (text blobs you paste into your AI client) plus one MCP server (one-line install) plus this hosted JSON registry. The agent looks up how to do things in apps, executes them deterministically, and verifies the result. Discover once, replay deterministically, fall back to vision when needed.

Designed to work with: Claude Desktop, Claude Code, Cursor, ChatGPT Desktop, Gemini CLI — any client that supports MCP. Web chat clients (chatgpt.com, claude.ai, gemini.google.com) are out of scope for v0.

Install

Run the MCP server locally:

npx @rosetta-skills/mcp
