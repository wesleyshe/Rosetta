Rosetta

Make every software, every website, every desktop app agentic.

Community registry of skills that lets any MCP-capable AI client drive desktop apps without per-app integration.

Install

v0 install is from source. Three commands.

git clone https://github.com/wesleyshe/Rosetta.git
cd Rosetta/mcp
npm install && npm run build

Then wire dist/index.js into your MCP client. Full guide: docs/install.md. macOS only in v0. npm one-liner lands post-launch.
