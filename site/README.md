# site/

Static website source. Vanilla HTML/CSS/JS, no framework. Served by the Railway backend (NOT GitHub Pages); the backend exposes this folder as static assets alongside the API.

Lands in Phase 2. Two views per app (human-readable + raw JSON), two copy-to-clipboard boxes for the seed skills (use + explore). Seed-skill text files live under `seed-skills/use.md` and `seed-skills/explore.md`.
